# Lab 04: Testing & Verification for Autonomous Software Engineering Platform

- **Difficulty**: Intermediate
- **Estimated Time**: 30 minutes

### Learning Objectives
- Write unit tests for tools and integration tests for the loop.
- Assert tool selection accuracy and error handling.

### Step-by-Step Instructions
1. Create unit test assertions using Pytest.
2. Mock external API calls to ensure reproducible test runs.
3. Run `python -m pytest`.

### Verification
All test assertions pass with exit code 0.
