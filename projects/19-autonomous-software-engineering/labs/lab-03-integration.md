# Lab 03: Integration & Loop Execution for Autonomous Software Engineering Platform

- **Difficulty**: Intermediate
- **Estimated Time**: 45 minutes

### Learning Objectives
- Connect the agent loop to tool dispatchers.
- Implement sliding-window memory management.

### Step-by-Step Instructions
1. Wire conversation history buffer to the agent loop.
2. Execute a multi-turn conversation requiring tools.
3. Inspect context window length after each turn.

### Expected Output
Agent invokes tools and summarizes findings accurately.
