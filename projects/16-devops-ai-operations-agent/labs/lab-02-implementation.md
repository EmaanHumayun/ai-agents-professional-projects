# Lab 02: Core Implementation for DevOps AI Operations Agent (AIOps)

- **Difficulty**: Intermediate
- **Estimated Time**: 45 minutes

### Learning Objectives
- Implement tool schemas and argument validation.
- Structure system prompt templates.

### Step-by-Step Instructions
1. Define tool functions with type hints.
2. Validate input arguments using Pydantic models.
3. Test tool execution with edge-case parameters.

### Expected Output
Tools execute deterministically and reject invalid types.
