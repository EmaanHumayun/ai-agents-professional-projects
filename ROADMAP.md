# Roadmap — Level 4: Professional

### Project 16: DevOps AI Operations Agent (AIOps)
- **Focus**: AIOps operational agent analyzing system logs, correlating Prometheus alerts, matching runbooks, and enforcing human-in-the-loop approvals.
- **Stack**: Python, Paramiko, Prometheus Client, Docker SDK, Alertmanager

### Project 17: AI Customer Support Multi-Agent Platform
- **Focus**: Enterprise support collective classifying intent, querying knowledge bases, managing CRM tickets, and escalating to human agents.
- **Stack**: Python, FastAPI, PostgreSQL, Redis, Zendesk/Slack Mock APIs

### Project 18: AI Business Operations Agent Platform
- **Focus**: Cross-system business process orchestrator automating invoice approval routing, audit logging, and role-based permissions.
- **Stack**: Python, FastAPI, RBAC, Cryptographic Audit Ledger, PostgreSQL

### Project 19: Autonomous Software Engineering Platform
- **Focus**: Autonomous repository worker resolving GitHub issues, editing code in ephemeral Docker containers, running tests, and opening PRs.
- **Stack**: Python, Docker SDK, Git, GitHub Apps API, Pytest

### Project 20: Enterprise Agentic AI Platform
- **Focus**: Cloud-native multi-tenant agent gateway running on Kubernetes with agent registry, model router, distributed queues, and OpenTelemetry.
- **Stack**: Python, FastAPI, Kubernetes (Helm), Redis, Celery, PostgreSQL, OpenTelemetry
